# Flotte Homebrew Tap

Homebrew formula for the [Flotte CLI](https://github.com/flotte-sh/cli).

```sh
brew install flotte-sh/tap/flotte-cli
```

This installs the `flotte` command. See the [CLI repository](https://github.com/flotte-sh/cli) for usage and the [documentation](https://docs.flotte.sh) for setup.

Report CLI issues in the [CLI repository](https://github.com/flotte-sh/cli/issues).
